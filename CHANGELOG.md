# CHANGELOG

## [1.1.0] | 2026.11.13

Changed
Honey Bee: redesigned as a pastel, minimal light theme.
One cream background (
#FBF3DC) across the whole UI: editor, sidebar, activity bar, tabs, panel, status bar, title bar, menus and inputs.
Dark brown text (
#3D2C07) replaces the old cream-on-gold text, which had very low contrast.
Honey gold (
#D9980D) is now used only for accents: active tab, cursor, badges, buttons, progress bar and scrollbar.
Softer syntax palette: sage strings, terracotta numbers, dusty blue types, muted rose parameters.
Darker pastel terminal colors for readability on light backgrounds.
Fixed
Deep Sea: theme file converted to valid VS Code format. UI colors now live in a proper colors object.
deep sea / honey bee: removed invalid token scopes (_url_, _link_, _uri_, and the | separator in the markdown heading scope) and fixed the capitalized Keyword and Storage scopes.
Added
Zed versions of deep sea and honey bee in the zed/ folder.
